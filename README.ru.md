# InkOS RU — русскоязычный форк InkOS

Это независимая развиваемая русскоязычная редакция проекта Narcooo/inkos, а не официальный выпуск оригинального разработчика.

**Статус:** разработка, не стабильный релиз. Не используйте эту ветку как единственное хранилище рукописей.

## Что добавляется

- Код языка ru для произведений и ru-RU для пользовательского интерфейса.
- Русский подсчёт слов, заголовки глав и кириллические идентификаторы.
- Русскоязычные инструкции агентов и литературные справочники.
- Поддержка форматов Markdown, TXT и EPUB с правильными метаданными языка.
- Тесты на совместимость с китайскими и английскими проектами.

## Запуск из исходников на Windows 11

Требования: Git, Node.js 22.16+ или 24, pnpm 9. В исходном проекте pnpm 11 не совместим с текущей конфигурацией замороженного lockfile.

Открыть PowerShell и выполнить:

    git clone https://github.com/perejaslav/inkos-ru.git
    cd inkos-ru
    git switch feat/russian-localization
    npx --yes pnpm@9.15.9 install --frozen-lockfile
    npx --yes pnpm@9.15.9 build
    npx --yes pnpm@9.15.9 test
    node packages/cli/dist/index.js --help

Команда создания проекта на русском:

    node packages/cli/dist/index.js init my-project --lang ru

Создание романа требует настроенного LLM-провайдера. Реальные внешние сервисы могут расходовать API-бюджет.

## Данные и безопасность

- Не публикуйте файлы конфигурации с API-ключами, пользовательские книги и журналы сеансов.
- Перед миграциями делайте резервную копию исходного проекта и проводите dry-run.
- Изменения кода разрабатываются в рабочей ветке, а исходный master сохраняет связь с upstream.
- Исходный npm release workflow отключён до выбора самостоятельного пространства имён и отдельного разрешения на публикацию.
