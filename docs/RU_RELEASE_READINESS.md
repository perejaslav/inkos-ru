## Сделано

- Язык ru в базовых моделях Work/книги и творческих подсистемах; ограничения silent ru→zh существенно сокращены.
- ru_words, русские заголовки глав и импорт, безопасные кириллические идентификаторы, совместимые EPUB-метаданные.
- Русские инструкции Planner/Writer/Reviewer/Reviser и критические промпты Story/Play/Forecast.
- Основная Studio RU, CLI/TUI RU, расширенные русские справочники Skills.
- Переносимый Windows Playwright launcher; актуализированы фикстуры и удалённые upstream проверки.
- Исходный workflow npm-публикации отключён, связь с upstream сохранена.

## Не подтверждено

- Реальное художественное качество LLM: локальный API на 127.0.0.1:8081 недоступен; использованы искусственные входные тексты, без внешних вызовов.
- Полнота всех редких русских интерфейсных строк, ошибок и творческих режимов.
- Реальный CI на обоих OS и двух Node-версиях: конфигурация изменена, запуск в GitHub должен быть проверен.
- Установка независимого опубликованного npm-пакета: не выбран scope и публикация не разрешена.
- Морфологический recall всего русского корпуса: ё/е проверено, склонения нуждаются в количественной оценке.

## Не выполнять до отдельного разрешения

Не создавать публичные release/tag, не публиковать npm, не перезаписывать пакеты upstream. Перед стабильным выпуском нужны итоговый UI аудит, проверки в GitHub CI, ручная генерация и литературный контроль на реальной LLM, самостоятельные имена пакетов.


## Оставшиеся продуктовые ограничения (явно не считать стабильным выпуском)

- Маршрут создания книги теперь открывает форму BookCreate с отдельным выбором ru. Полноценный поток создания через реальную LLM и E2E этой формы ещё не проверен.
- Начальная настройка LanguageSelector теперь позволяет выбрать ru как язык проекта отдельно от локали интерфейса.
- Не все редко используемые элементы Studio и динамические сообщения Play/HUD имеют локализацию; некоторые показываются по-английски.
- Морфология русского поиска (падежи) и реальное качество LLM остаются NOT VERIFIED.

Следовательно это предрелизная рабочая ветка, а не готовый стабильный релиз. Публикацию останавливают не только разрешение пользователя, но и эти незакрытые требования плана.
